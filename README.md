# 📂 SQL Projects

# 1.Banking Fraud Transaction Analysis using SQL

## Project Overview

This project focuses on analyzing banking transaction data to identify fraudulent activities, detect suspicious transaction patterns, and generate actionable insights using SQL. The analysis aims to support financial institutions in strengthening fraud prevention strategies and improving transaction monitoring systems.

## Key Analysis Performed

* Fraudulent vs. legitimate transaction analysis
* High-risk customer identification
* Transaction amount and frequency analysis
* Suspicious transaction pattern detection
* Customer behavior and spending trend analysis
* Geographic and channel-based transaction insights
* Risk segmentation and anomaly detection
* Data cleaning, transformation, and validation

## SQL Concepts Applied

* Complex JOIN Operations
* Common Table Expressions (CTEs)
* Window Functions
* Aggregate Functions
* Subqueries
* Conditional Logic (CASE Statements)
* Data Filtering and Grouping
* Fraud Pattern Identification Queries

## Tools Used

* SQL
* MySQL/PostgreSQL (update as applicable)
* GitHub for Version Control

## Business Impact

The analysis provides valuable insights into transaction behavior, highlights potential fraud risks, and supports data-driven decision-making for fraud detection, risk management, and financial security operations.

## Outcome

Developed a comprehensive SQL-based fraud analytics framework capable of uncovering suspicious transaction patterns and delivering meaningful insights to enhance banking security and operational efficiency.



# 2.Zomato Restaurant Data Analysis using SQL

## Project Overview

This project focuses on analyzing Zomato restaurant data using SQL to uncover valuable insights into restaurant performance, customer preferences, pricing trends, ratings, and market dynamics. The objective is to transform raw data into actionable business intelligence that can support strategic decision-making in the food and hospitality industry.

## Key Analysis Performed

* Restaurant rating and performance analysis
* City-wise and locality-wise restaurant distribution
* Cuisine popularity and customer preference analysis
* Price range and affordability insights
* Online delivery and table booking trends
* Restaurant ranking and top-performing outlet identification
* Customer rating behavior analysis
* Data cleaning, transformation, and aggregation

## SQL Concepts Applied

* Complex JOIN Operations
* Common Table Expressions (CTEs)
* Window Functions
* Aggregate Functions
* Subqueries
* CASE Statements
* GROUP BY and HAVING Clauses
* Ranking and Performance Analysis Queries

## Tools Used

* SQL
* MySQL/PostgreSQL (update as applicable)
* GitHub for Version Control

## Business Impact

The analysis helps identify customer dining preferences, high-performing restaurants, popular cuisines, pricing strategies, and market opportunities. These insights can support restaurant owners, food delivery platforms, and business stakeholders in making data-driven decisions.

## Outcome

Developed a comprehensive SQL-based restaurant analytics solution that provides meaningful insights into customer behavior, restaurant performance, and food industry trends, enabling improved business strategy and operational efficiency.
